# Clean Car API

API для сервиса бронирования автомойки. Проект позволяет записываться на мойку, выбирать услуги, боксы, мойщиков, просматривать свои записи и управлять бронированием через веб-интерфейс и VK-бота.

---

## 🌐 Проект работает на сервере по ссылке
[https://milojop.pythonanywhere.com/](https://milojop.pythonanywhere.com/)

## 🛠 Использованный технологический стек

- **Python 3.12** — язык программирования
- **Django 4.2** — веб-фреймворк
- **Django REST Framework 3.15** — создание API
- **ORM Django** — взаимодействие с базой данных
- **Simple JWT** — аутентификация через JWT-токены
- **SQLite** — база данных (по умолчанию)
- **Djoser** — управление пользователями и аутентификация
- **VK API** — интеграция с VK-ботом
- **vk_api** — работа с ботом

## 📝 Описание проекта

**Clean Car** — это сервис онлайн-бронирования автомойки, который помогает клиентам быстро и удобно подобрать услугу и время для обслуживания автомобиля.

Проект построен на принципах баланса и эффективности: записи распределяются между мойщиками таким образом, чтобы нагрузка была равномерной. Каждый клиент видит все доступные боксы, а в случае занятости конкретного мойщика или бокса, система автоматически подбирает альтернативные варианты, сохраняя возможность записи.

Все мойщики работают строго по установленному графику и имеют категорию, которую назначает администратор. Это позволяет гибко управлять доступом к услугам: специалист с более низкой квалификацией не может быть назначен на услугу, требующую более высокой категории. Каждый мойщик видит только те записи, которые система определила ему в работу.

Сервис остаётся удобным и эффективным даже в минимальной конфигурации — при наличии всего одного бокса и одного мойщика, что делает его универсальным решением для автомоек любого масштаба.

## Как запустить проект

### 1. Клонировать репозиторий.

```bash
git clone https://github.com/Kirullk/clean-car.git
```

### 2. Создать и активировать виртуальное окружение.

```bash
python3 -m venv venv
source venv/bin/activate  # для Linux/macOS
# venv\Scripts\activate  # для Windows
```

### 3. Установить зависимости.

```bash
pip install -r requirements.txt
```

### 4. Выполнить миграции базы данных.

```bash
python manage.py migrate
```

## Чтобы добавить сервисные услуги, мойщиков, часы работы и прочее, нужно перейти в админку, для этого создайте админа:

```bash
python manage.py createsuperuser
```
