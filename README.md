# Clean Car API

API для сервиса бронирования автомойки. Проект позволяет записываться на мойку, выбирать услуги, боксы, мойщиков, просматривать свои записи и управлять бронированием через веб-интерфейс и VK-бота.

---

## Проект работает на сервере по ссылке https://milojop.pythonanywhere.com/.

## Использованный технологический стек

- **Python 3.12** — язык программирования
- **Django 4.2** — веб-фреймворк
- **Django REST Framework 3.15** — создание API
- **ORM Django** — взаимодействие с базой данных
- **Simple JWT** — аутентификация через JWT-токены
- **SQLite** — база данных (по умолчанию)
- **Djoser** — управление пользователями и аутентификация
- **VK API** — интеграция с VK-ботом
- **vk_api** — работа с ботом

## Как запустить проект

### 1. Клонировать репозиторий.

```bash
git clone https://github.com/Kirullk/clean-car.git
```

### 2. Создать и активировать виртуальное окружение.

```bash
python3 -m venv venv
source venv/bin/activate  # для Linux/macOS
# venv\Scripts\activate  # для Windows
```

### 3. Установить зависимости.

```bash
pip install -r requirements.txt
```

### 4. Выполнить миграции базы данных.

```bash
python manage.py migrate
```

## Чтобы добавить сервисные услуги, мойщиков, часы работы и прочее, нужно перейти в админку, для этого создайте админа:

```bash
python manage.py createsuperuser
```


### Данный сервис позволяет помочь пользователю выбрать удобную для услугу, в удобное для себя время. Логика данного проекта расчитана на то, чтобы предоставлять наиболее оптимальные условия как для работодателя с точки зрения бизнес логики, так и пользователя. Записи распределяются таким образом, чтобы у всех мойщиков было равное количество заказов. Все доступные боксы предоставляются для записи клиенту, при записи в один, запись не пропадает, она переназначается другим боксом и мойщиком, в случае возможности предоставления таковых. Все мойщики работают строго по фиксированному графику. Каждый мойщик видит записи, если система определила его. Также у мойщиков есть категория,которую ему проставляет администратор, специалист с меньшей квалификацией, не может назначиться на услугу, которая требует определенной категории. ###
