# Clean Car

Проект позволяет записываться на мойку, выбирать услуги, боксы, мойщиков, просматривать свои записи и управлять бронированием через веб-интерфейс и VK-бота.

## 🛠 Использованный технологический стек

- **Python 3.12** — язык программирования
- **Django 4.2** — веб-фреймворк
- **Django REST Framework 3.15** — создание API
- **ORM Django** — взаимодействие с базой данных
- **Simple JWT** — аутентификация через JWT-токены
- **SQLite** — база данных (по умолчанию)
- **Djoser** — управление пользователями и аутентификация
- **VK API** — интеграция с VK-ботом
- **vk_api** — работа с ботом

## 📝 Описание проекта

**Clean Car** — это сервис онлайн-бронирования автомойки, который помогает клиентам быстро и удобно подобрать услугу и время для обслуживания автомобиля.

Проект построен на принципах баланса и эффективности: записи распределяются между мойщиками таким образом, чтобы нагрузка была равномерной. Каждый клиент видит все доступные боксы, а в случае занятости конкретного мойщика или бокса, система автоматически подбирает альтернативные варианты, сохраняя возможность записи.

Все мойщики работают строго по установленному графику и имеют категорию, которую назначает администратор. Это позволяет гибко управлять доступом к услугам: специалист с более низкой квалификацией не может быть назначен на услугу, требующую более высокой категории. Каждый мойщик видит только те записи, которые система определила ему в работу.

Сервис остаётся удобным и эффективным даже в минимальной конфигурации — при наличии всего одного бокса и одного мойщика, что делает его универсальным решением для автомоек любого масштаба.

Проект также предоставляет ВКбота, который выполняет все вышеупомянутные функции сервиса.

## Как запустить проект

### 1. Клонировать репозиторий.

```bash
git clone https://github.com/Kirullk/clean-car.git
```

### 2. Создать и активировать виртуальное окружение.

```bash
python3 -m venv venv
source venv/bin/activate  # для Linux/macOS
# venv\Scripts\activate  # для Windows
```

### 3. Установить зависимости.

```bash
pip install -r requirements.txt
```

### 4. Выполнить миграции базы данных.

```bash
python manage.py migrate
```

### 5. Чтобы добавить сервисные услуги, мойщиков, часы работы и прочее, нужно перейти в админку, для этого создайте админа:

```bash
python manage.py createsuperuser
```

## Запуск VK-бота

### 1. Получить токен VK
1. Создайте сообщество ВКонтакте (группу)
2. Перейдите в **Управление** → **Работа с API**
3. Создайте ключ доступа с правами на **сообщения**
4. Скопируйте полученный токен

### 2. Настроить переменные окружения.
Создай файл `.env` в корне проекта (если ещё нет) и добавь:

```python
VK_TOKEN=ваш_токен_сообщества
GROUP_ID=айди_группы
```

### 3. Активировать виртуальное окружение.
```bash
source venv/bin/activate 
```

### 4. Запустить бота.
```bash
python manage.py run_vk_bot
```
## Взаимодействие с VK-ботом через API

Бот не работает напрямую с базой данных — все запросы к серверу выполняются через API.

**Как это работает:**

- При выборе услуги бот обращается к эндпоинту `/api/v1/services/` и получает список услуг.
- При записи отправляет POST-запрос на `/api/v1/appointments/` с данными клиента.
- Для просмотра записей использует GET-запрос на `/api/v1/appointments/` с токеном пользователя.
- Все ответы API приходят в формате JSON, бот форматирует их в сообщения.

Это позволяет легко масштабировать систему: при необходимости бота можно заменить на сайт, мобильное приложение или телеграм-бота — API останется прежним.
